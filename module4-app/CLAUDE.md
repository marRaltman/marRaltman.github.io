# module4-app — Artistic Intelligence (AI)

Module 4 project: an app concept called **Artistic Intelligence**, or **AI** for short. It's a planner for any craft or DIY project (sewing, painting, woodworking, crochet, upcycling, home fixes, anything) that also suggests a small creative task every day, from easy to hard.

The name is a deliberate play on "artificial intelligence." Keep the full name "Artistic Intelligence" on first mention in each file so readers get the joke and don't think it's an AI-tech product.

## Files and order

1. `problem.md` — who is stuck and why. Everything else builds on this.
2. `evidence.md` — data and observations that show the problem is real.
3. `solution.md` — what the app does, mapped back to each problem point.
4. `web-page.md` — landing-page copy for the app.
5. `ad-script.md` — a 30-second video ad script.

If the problem changes, update the files downstream of it so they stay consistent.

## Two halves of the app

- **Project planner:** the user's own projects, with materials, cost, steps, time, and deadlines.
- **Daily creative tasks:** one small prompt a day in three levels: **Sketch** (about 5 minutes), **Study** (about 30 minutes), **Masterpiece** (a weekend or longer). Keep these level names the same in every file.

## Rules

- Written in Marley's voice: plain, specific, a little warm. No "delve," "in today's world," or hype words like "revolutionary."
- Every statistic in `evidence.md` needs a source. Never invent numbers, survey results, or quotes. Mark anything not yet gathered as `TODO`.
- These are markdown planning docs, not live site pages. Don't link them from `index.html` or the nav unless asked.
- Don't commit or push without explicit confirmation (same rule as the repo's root `CLAUDE.md`).
